## 内容与流程

六份用户提供的 PDF 共 95 页，全部页面文字保存在 `lib/handouts/books.json`。保留页码，可搜索、展开和标记已读。分数与上下标已对照 PDF 渲染校对；精确住址脱敏，原始 PDF 不发布。

每门课从原文件选取一个连贯片段作为重点听说练习（共 40 句），并明确标记出处。不是把全部 95 页都做成听写或朗读。教师补充的中文译文、语法、词汇、句式迁移和文化提醒另列在 `practice.json` 中。教材中的学校和履历是角色示例，不是使用者的个人经历。级别为教学建议。

1. 中文预习：尝试表达彩色语块，记录第一次表达。
2. 无字幕盲听：只显示音频播放条，支持拖动、调速与循环，不显示视频画面。
3. 听音填空：真实音频进度、检查答案、错句重听、参考答案、重新练习。
4. 双语对照：字幕、单句喇叭与可选跟读录音。
5. 本期精讲：语法、短语、词汇，以及完整原课件。
6. 文本回顾：句式模板、可播放例句、自主表达与前后对照。
7. 文化与交流提醒。

## 音频

88 个单独朗读文件（40 句课文、18 个短语、18 个词汇、12 个模板例句），6 段完整音轨、6 个课件视频和双语字幕。全部使用本机 macOS 离线合成，英语 `Daniel / en_GB`，法语 `Thomas / fr_FR`。不是真人、BBC 原声或云端神经语音；没有向外部 TTS 服务上传课件文本。

网页使用静态音频文件，不依赖浏览器 `speechSynthesis`。播放进度和字幕来自实际音频时间轴，支持慢速、循环、拖动与单句重播；同一时间只有一个播放器发声。录音仅留在内存中，刷新前须自行下载。

## 手机、平板与电脑

同一个网址自动适应屏幕：电脑三列课程、平板两列、手机单列。讲义在小屏上收窄页边距，音频控件分行排列，播放/调速/循环按钮保留，点击区域至少 44px。输入框使用 16px 基准字号、关闭听写自动纠词；支持刘海屏安全边距、横竖屏重排和浏览器缩放，不锁定缩放比例。课程数据与进度存储方式不变。

## 本地保存与备份

- 当前语言：`handout-language`。
- 每门课程独立存储：`language-handouts-v2:<course-id>`。
- 保存输入、检查/查看答案状态、笔记、已读页码和精练完成标记。
- 导入/导出当前课程 JSON 备份；导入须匹配课程并确认替换。设备、浏览器、域名之间不自动同步。
- 原版英语 / 法语的旧存储键不删除，旧媒体与源数据保留，但不出现在新版首页。

听写忽略大小写、标点、空格及部分英语缩写；保留法语重音要求。查看答案后不计独立答对，重新练习后可再测。自由表达和录音不做自动评分。

## 维护课程

- `lib/handouts/catalog.ts`：语言、课程标题、页数和级别。
- `lib/handouts/books.json`：脱敏后的完整课件。
- `lib/handouts/practice.json`：选段与配套练习。
- `components/handout-lesson.tsx`：七段式讲义。
- `scripts/import-handouts.py --source-dir <PDF目录>`：导入与公式校对；需要 pdfplumber。
- `scripts/prepare-handout-audio.py`：macOS 离线生成语音、时间轴、视频与字幕；需要 imageio-ffmpeg 和本机语音服务。

修改练习文本后必须重建音频，运行测试校验原文对应、音频文件、字幕、语言与存储隔离。不要将未校对的 PDF 提取公式直接当作数学答案，也不要将合成音频标为真人原声。
