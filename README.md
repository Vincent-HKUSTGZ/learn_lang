# 法语，正在发生

一个为中文母语法语初学者设计的 Vlog 学习网站。目前包含一门完整课程：**地道法语积累005 · Le jardin est si joli**。

## 学习流程

- 先用已有法语表达场景
- 无字幕盲听
- 10 题听写挑战
- 逐句中法精听
- 语法、短语、词汇与文本回顾
- 口语输出与法国文化

学习进度和口语笔记保存在访问者自己的浏览器中。

## 本地运行

```bash
pnpm install
pnpm dev
```

## GitHub Pages

```bash
pnpm build:pages
```

静态网站生成到 `docs/`，可由 GitHub Pages 直接发布。
